Access

    The draft is sent to Anthropic's Claude API for analysis. Treat the results as a reviewer's checklist, not a final judgment. Charts and images in the document aren't read.

    Start with a draft

    Add the current draft on the left and select Analyze draft. A full analysis usually takes two to four minutes. You'll get:

    • A one-page summary of the review and its main concerns
    • A SWOT analysis grounded in the draft's own data
    • Gaps: missing sections, inconsistencies, weak evidence, and recommendations that don't match the findings
    • Automated checks for leftover template text, empty appendices, blank table rows, and math errors
    • Suggested wording fixes, a comparison with an earlier draft, and a team email
    • A Word version of the full report

    Enter your access details on the left to run the full analysis. Without them, only the automated checks run.
